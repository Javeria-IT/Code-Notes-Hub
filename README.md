# 💻 CodeNotes Hub

> **A modern, responsive platform for developers to learn, organize, and access programming notes easily.**

CodeNotes Hub is a frontend-based educational website designed for students and developers who want a simple and organized place to explore programming concepts, notes, and useful coding resources.

The project is built using **HTML, CSS, and JavaScript** with a clean and responsive user interface.

---

## ✨ Features

* 🔐 **User Login & Registration**
* 🏠 **Modern Home Page**
* 📚 **Programming Notes & Resources**
* 💻 **Developer-Friendly Interface**
* 📱 **Fully Responsive Design**
* 🌙 **Dark & Light Theme**
* 🎨 **Modern Gradient UI**
* 📩 **Contact Us Section**
* 🔙 **Easy Page Navigation**
* ⚡ **Fast & Lightweight**
* 💾 **LocalStorage-based User Data**
* 🖥️ **Clean Dashboard Interface**

## 🎨 UI & Design

CodeNotes Hub focuses on a clean and modern developer-oriented design.

### Design Highlights

* Modern gradient backgrounds
* Smooth hover animations
* Rounded cards and buttons
* Responsive layouts
* Dark/Light theme support
* Developer-focused visual style
* Poppins font for a clean appearance

---

## 🌙 Dark & Light Mode

CodeNotes Hub includes a **Dark/Light Theme Toggle** that allows users to switch between different visual modes according to their preference.

The theme is managed using JavaScript and CSS variables for consistent styling across pages.

---

## 🔐 Authentication

The project includes a basic frontend authentication system using **JavaScript and LocalStorage**.

Users can:

1. Create an account
2. Login using their credentials
3. Access the dashboard
4. Logout from their account

> **Note:** This is a frontend demonstration project. It does not use a production backend authentication system.
