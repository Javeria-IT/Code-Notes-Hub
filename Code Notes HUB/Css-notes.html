CSS Complete Notes

Introduction to CSS

CSS stands for Cascading Style Sheets. It describes how HTML elements should be displayed on screen, paper, or in other media. CSS saves a lot of work because it can control the layout of many web pages all at once, and it separates presentation from structure. 

<link rel="stylesheet" href="style.css">

Selectors

Selectors are patterns used to select the element(s) you want to style. The most common are the element selector, class selector, and ID selector. 

p { color: red; }

.card { padding: 20px; }

#logo { font-weight: bold; }

Colors

CSS colors can be defined using names, HEX, RGB, RGBA, HSL, or HSLA values. RGBA and HSLA also let you control opacity. 

h1 { color: tomato; }

p { color: #3B82F6; }

div { background: rgba(139, 92, 246, 0.5); }

Fonts

The font-family property sets the typeface, while font-size, font-weight, and font-style control size, boldness, and slant. Always provide fallback fonts. 

body {
  font-family: 'Poppins', Arial, sans-serif;
  font-size: 16px;
  font-weight: 500;
}

Box Model

Every HTML element is a rectangular box made up of content, padding, border, and margin. Understanding the box model is essential for layout and spacing. 

.box {
  width: 200px;
  padding: 20px;
  border: 2px solid #333;
  margin: 10px;
  box-sizing: border-box;
}

Flexbox

Flexbox is a one-dimensional layout system for arranging items in a row or column, with powerful alignment and spacing controls. 

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}

CSS Grid

CSS Grid is a two-dimensional layout system that lets you arrange items into rows and columns at the same time. 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Positioning

The position property controls how an element is placed in the document: static (default), relative, absolute, fixed, or sticky. 

.modal {
  position: fixed;
  top: 20px;
  right: 20px;
}

Responsive Design

Responsive design makes a website look great on every screen size, typically using fluid grids, flexible images, and media queries. 

img {
  max-width: 100%;
  height: auto;
}

Media Queries

Media queries apply CSS rules only when certain conditions are met, such as a maximum screen width, allowing layouts to adapt. 

@media (max-width: 768px) {
  .sidebar {
    display: none;
  }
}
