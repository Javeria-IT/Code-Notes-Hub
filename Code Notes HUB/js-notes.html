JavaScript Complete Notes

Introduction

JavaScript is the programming language of the web. It runs in every browser and lets you make pages interactive - responding to clicks, validating forms, updating content without reloading, and much more. It can also run outside the browser, for example with Node.js.

console.log("Hello, JavaScript!");

Variables

Variables store data so it can be used and changed later. Use let for values that change, const for values that shouldn't be reassigned, and avoid var in modern code since it doesn't respect block scope.

let score = 10;
const studentName = "Ayesha";
score = score + 5;

Data Types

JavaScript has primitive types - string, number, boolean, undefined, null, symbol, bigint - and one big non-primitive type: object (which includes arrays and functions).

let name = "Ali";        // string
let age = 21;             // number
let isStudent = true;     // boolean
let empty = null;         // null
let notSet;                // undefined

Operators

Operators perform actions on values: arithmetic (+ - * / %), assignment (= += -=), comparison (== === != !==), and logical (&& || !). Always prefer === over == to avoid unexpected type coercion.

let total = 5 + 3;         // 8
let isEqual = 5 === "5";   // false
let isTrue = true && false; // false

Conditions

Conditional statements run code only when a condition is true. Use if / else if / else for branching logic, or a switch statement when comparing one value against many options.

let hour = 14;

if (hour < 12) {
  console.log("Good Morning");
} else if (hour < 18) {
  console.log("Good Afternoon");
} else {
  console.log("Good Evening");
}

Loops

Loops repeat a block of code. for is ideal when you know how many times to repeat; while repeats while a condition stays true; for...of is a clean way to loop over arrays.

for (let i = 0; i < 5; i++) {
  console.log(i);
}

const fruits = ["apple", "mango"];
for (const fruit of fruits) {
  console.log(fruit);
}

Functions

Functions are reusable blocks of code. They can be declared with the function keyword or written as compact arrow functions, and can accept parameters and return a value.

function add(a, b) {
  return a + b;
}

const multiply = (a, b) => a * b;

console.log(add(2, 3));       // 5
console.log(multiply(2, 3));  // 6

Arrays

Arrays store ordered lists of values. Common methods include push and pop to add/remove from the end, map to transform every item, and filter to keep only matching items.

const numbers = [1, 2, 3, 4];

numbers.push(5);

const doubled = numbers.map(n => n * 2);

const evens = numbers.filter(n => n % 2 === 0);

Objects

Objects store data as key-value pairs, useful for representing real-world things like a student or a product. You can access and update properties using dot or bracket notation.

const student = {
  name: "Sara",
  age: 20,
  isEnrolled: true
};

console.log(student.name);
student.age = 21;

DOM

The DOM (Document Object Model) is how JavaScript "sees" an HTML page - as a tree of elements it can read and change. You can select elements and update their content, styles, or attributes.

const title = document.getElementById("title");

title.innerText = "Updated Title!";

title.style.color = "blue";

Events

Events let you run code in response to user actions like clicks, key presses, or form submissions, using addEventListener rather than inline HTML attributes.

const button = document.querySelector("button");

button.addEventListener("click", () => {
  alert("Button clicked!");
});

ES6

ES6 (ECMAScript 2015) introduced many features still used daily: let/const, arrow functions, template literals, destructuring, and the spread operator.

const { name, age } = student;

const greeting = `Hello, ${name}!`;

const merged = [...numbers, 6, 7];

Async / Await

Async/await makes working with asynchronous operations (like fetching data from an API) read like normal, top-to-bottom code, instead of chaining .then() callbacks.

async function getUser() {
  const response = await fetch("https://api.example.com/user");
  const data = await response.json();
  console.log(data);
}
