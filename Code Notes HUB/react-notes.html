React Complete Notes

Introduction

React is a JavaScript library for building user interfaces out of small, reusable pieces called components. Instead of manually updating the page, you describe what the UI should look like for a given state, and React updates the DOM efficiently for you.

function App() {
  return <h1>Hello, React!</h1>;
}

Components

Components are the building blocks of a React app - independent, reusable pieces of UI, usually written as JavaScript functions that return markup.

function Welcome() {
  return <h2>Welcome back!</h2>;
}

export default Welcome;

JSX

JSX lets you write HTML-like syntax directly inside JavaScript. It gets compiled into regular JavaScript function calls. Every JSX expression must return a single root element (or a fragment).

const element = (
  <div>
    <h1>Title</h1>
    <p>Some text</p>
  </div>
);

Props

Props ("properties") pass data from a parent component down to a child component. They are read-only - a child should never modify its own props.

function Greeting(props) {
  return <h2>Hello, {props.name}!</h2>;
}

<Greeting name="Sara" />

State

State is data that belongs to a component and can change over time. When state changes, React automatically re-renders the component to reflect the new value.

const [count, setCount] = useState(0);

setCount(count + 1); // triggers a re-render

Events

React events are named using camelCase (like onClick) and are passed a function directly, rather than a string, unlike plain HTML.

function Button() {
  function handleClick() {
    alert("Clicked!");
  }

  return <button onClick={handleClick}>Click Me</button>;
}

Hooks

Hooks are functions that let function components use React features like state and lifecycle behavior. All hooks start with "use" - useState and useEffect are the two you'll reach for most often.

import { useState, useEffect } from "react";

useState

useState adds a piece of local state to a component. It returns the current value and a setter function, and calling the setter re-renders the component with the new value.

const [name, setName] = useState("Guest");

<button onClick={() => setName("Ali")}>
  Set Name
</button>

useEffect

useEffect runs "side effects" after a component renders - things like fetching data, subscribing to something, or updating the document title. The dependency array controls when it re-runs.

useEffect(() => {
  document.title = `Count: ${count}`;
}, [count]);

Forms

In React, form inputs are usually "controlled" - their value is driven by state, and every keystroke updates that state through an onChange handler.

const [email, setEmail] = useState("");

<input
  value={email}
  onChange={(e) => setEmail(e.target.value)}
/>

Conditional Rendering

You can show different UI based on a condition using a ternary operator, the && operator, or a plain if statement before the return.

{isLoggedIn ? (
  <p>Welcome back!</p>
) : (
  <p>Please log in.</p>
)}

API Integration

Combining useEffect and useState is the standard way to fetch data from an API when a component loads, and store the result in state so it can be rendered.

const [users, setUsers] = useState([]);

useEffect(() => {
  fetch("https://api.example.com/users")
    .then(res => res.json())
    .then(data => setUsers(data));
}, []);
