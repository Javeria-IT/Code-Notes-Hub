Tailwind CSS Complete Notes

Introduction

Tailwind CSS is a utility-first CSS framework. Instead of writing custom CSS classes, you style elements by combining small, single-purpose utility classes directly in your HTML.

<h1 class="text-2xl font-bold text-blue-600">
  Hello Tailwind
</h1>

Installation / Setup

Tailwind can be installed via npm as part of a build process, or included quickly through the Play CDN for prototyping and learning.

npm install -D tailwindcss
npx tailwindcss init

<!-- or, for quick prototyping -->
<script src="https://cdn.tailwindcss.com"></script>

Utility Classes

A utility class does one small job - like setting padding, a text color, or a border radius. You combine many utilities to build a fully styled element without leaving your HTML.

<button class="px-4 py-2 bg-blue-500 text-white rounded-lg">
  Click Me
</button>

Colors

Tailwind ships with a large default color palette, each with shades from 50 (lightest) to 900 (darkest), applied through prefixes like text-, bg-, and border-.

<div class="bg-purple-600 text-white">
  Purple Box
</div>

Typography

Text size, weight, alignment, and line height are all controlled with utilities like text-lg, font-semibold, text-center, and leading-relaxed.

<p class="text-lg font-semibold text-center leading-relaxed">
  Styled paragraph text
</p>

Spacing

Padding (p-) and margin (m-) utilities use a consistent numeric scale, and can target one side (pt-, mb-) or an axis (px-, my-).

<div class="p-6 mt-4 mb-2 px-8">
  Spaced box
</div>

Flexbox

The flex class turns on flexbox, and utilities like justify-between, items-center, and gap-4 handle alignment and spacing between flex items.

<div class="flex items-center justify-between gap-4">
  <span>Left</span>
  <span>Right</span>
</div>

Grid

The grid class turns on CSS Grid, and grid-cols-* sets the number of columns, while gap-* controls spacing between grid items.

<div class="grid grid-cols-3 gap-6">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>

Responsive Design

Tailwind is mobile-first: unprefixed utilities apply to all sizes, and prefixes like sm:, md:, lg: apply a utility only at that breakpoint and up.

<div class="text-sm md:text-lg lg:text-2xl">
  Responsive text
</div>

Hover / Focus States

State prefixes like hover: and focus: apply a utility only in that state, so you can style interactions without writing any custom CSS or JavaScript.

<button class="bg-blue-500 hover:bg-blue-700 focus:ring-2">
  Hover Me
</button>

Components

Because repeating long class lists can get messy, Tailwind projects often extract repeated patterns into reusable components (in React, Vue, etc.) or use the @apply directive inside a CSS file.

.btn-primary {
  @apply px-4 py-2 bg-blue-600 text-white rounded-lg;
}
